# Packaging Technology Teaching Assistant

Team Boadu capstone. A Gemma 3 1B model fine-tuned with LoRA to coach Ghanaian packaging students.

- `DATA_CARD.md` describes the dataset.
- `MODEL_CARD.md` describes the model, training results and known problems.
- `notebooks/` holds the Colab notebooks (training, evaluation, demo).
- `data/` holds the train, validation and test dialogues and the review sheets.
- `data_building/` holds the scripts that generate the dataset (`python build_v3.py`).
- `evaluation/` holds the model replies on test examples.
