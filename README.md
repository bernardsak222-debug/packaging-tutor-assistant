# Packaging Technology Teaching Assistant (Team Boadu capstone)

LoRA fine-tune of Gemma 3 for coaching Ghanaian packaging students.

- `DATA_CARD.md`, `MODEL_CARD.md`
- `notebooks/`: Colab notebooks (training, evaluation, demo)
- `data/`: train/val/test dialogues and instructor-review CSVs
- `data_building/`: scripts that generate the dataset (run `python build_v3.py`)
